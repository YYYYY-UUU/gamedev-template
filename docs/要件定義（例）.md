# 要件定義シート（記入例）

## 1. どんなゲーム？

敵を避けながらコインを集めるゲーム。

操作：矢印キーで上下左右に動く。

## 2. 勝ち条件 / 負け条件

- 勝ち：コインを10枚集めたらクリア画面が出る
- 負け：敵に3回当たったらゲームオーバー画面が出る

## 3. 作らないもの

- BGM と効果音は作らない
- ステージは1つだけ。2面以降は作らない
- セーブ機能・ランキングは作らない

## 4. これができたら完成

1. プレイヤーが矢印キーで上下左右に動く
2. コインに触れると、コインが消えて枚数が1増える
3. 10枚集めるとクリア画面が出る
4. 敵に当たるとHPが1減り、0になるとゲームオーバー画面が出る
