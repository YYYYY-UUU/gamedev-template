要件定義書

## 1. どんなゲーム？
自分と敵がサイコロ(1D6)を振り、爆弾(に書かれている数字)を爆発(超過)しないように耐えるゲーム

操作：スペースキー → サイコロを振る、決定
　　　スペースキー → 安全なサイコロ（1~3）
　　　Dキー → 危険なサイコロ（2~6）
　　　Bキー → プレイ中はパス（1ゲーム2回まで）、ゲームオーバー時はタイトルへ戻る

## 2. 勝ち条件 / 負け条件
自分の勝利条件：「敵がサイコロを振って出した目」が「お互いの出した目の合計」に足されたときに、爆弾の数字を超過する
自分の敗北条件：「自分がサイコロを振って出した目」が「お互いの出した目の合計」に足されたときに、爆弾の数字を超過する

## 3. 作らないもの
- アイテムなどのお助けアイテムは作らない
- 背景やBGMなどは作らない
- 特殊ルールは作らない

## 4. これができたら完成
- 自分→敵→自分→敵・・・の順番にサイコロ(1D6)を振り、出た目を合計の数字に足していく(自分はスペースキーでサイコロを振れ、相手は自動で振る)-
- 合計の数字が爆弾に書かれている数字を超過したら、そのターンにサイコロを振ったプレイヤーが負ける
- 爆弾の値は20~40から1ゲームごとにランダムに決まる
- プレイヤーはBキーでパスできる。パスは1ゲームにつき2回までで、パス後は敵のターンになる
- プレイヤーは安全なサイコロ（1~3）と危険なサイコロ（2~6）を選べる
- 敵の行動パターンは慎重・攻撃的・様子見の3種類で、対戦ごとにランダムに決まる
