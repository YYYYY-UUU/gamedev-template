# 設計

## 登場するオブジェクト|持っている情報

- プレイヤー｜座標(x,y)、出た目の数

- 敵|座標(x,y)、出た目の数(敵)

- サイコロ(敵・味方)|座標(x,y)、乱数
- 安全なサイコロ|1~3の乱数、スペースキー
- 危険なサイコロ|2~6の乱数、Dキー
- 敵の行動パターン|慎重・攻撃的・様子見から対戦ごとにランダム

- 爆弾と爆弾の数字|座標(x,y)、爆弾の数字

- 敵と味方の合計の数字|座標(x,y)、現在の合計の数字

- HUD|ターン管理、爆発する条件を満たしているか

## 状態

- タイトル --スペースキー-->プレイ中

- プレイ中--スペースキー-->タイトル
- プレイ中--Bキー（残り回数あり）-->敵のターン

- プレイ中--Escキー-->ポーズ

- プレイ中--爆弾が自ターンに爆発-->ゲームオーバー

- ゲームオーバー--スペースキー-->プレイ中

- ゲームオーバー--Bキー-->タイトル
